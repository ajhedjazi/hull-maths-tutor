# Human / Hull — design reference only

This folder contains a standalone conceptual homepage and design reference materials for the proposed Hull Maths Tutor redesign. It is **not** a replacement for the production website.

## What to inspect
- `Human_Hull_Full_Homepage_Concept.html` — standalone visual reference. Includes non-production demo interactions; do not copy its form behaviour or analytics assumptions into the production site.
- `assets/amir-homepage-hero.webp` — edited portrait photograph used in the demo. Confirm the school/photographer image usage rights before any public commercial use.
- `desktop_preview.png` and `mobile_preview.png` — design snapshots for visual comparison.
- `Human_Hull_Full_Homepage_Design_Proposal.md` — complete design rationale.
- `*_DRAFT.md` — candidate rules only; do not treat as approved instructions.

## Requirements for any future implementation
Preserve production pages, SEO metadata, canonical URLs, content, link structure, analytics, working Netlify forms and notifications, accessibility, and accurate pricing. Avoid including any identifiable pupil without appropriate permissions. No production edits, commit, push, merge or deploy until expressly approved by the user.

The concept page is for comparison, not a drop-in replacement for `/index.html`.
